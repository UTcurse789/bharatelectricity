# Design system

Design read: international B2B energy event, confident editorial and photographic, accessible to a broad professional audience.
Taste dials: DESIGN_VARIANCE 5, MOTION_INTENSITY 3, VISUAL_DENSITY 4.

- Brand: POWERGEN burgundy #98314e sampled from the official header; Bharat orange/green preserved in the original artwork; navy #172132 for photographic contrast and type.
- Typeface: self-hosted variable Manrope, 16px body, 1.7 line height; measured display hierarchy with tight heading tracking.
- Width: 1280px content, 48px desktop gutters, 20px mobile gutters.
- Spacing: 88px desktop and 58px mobile section rhythm; 24-30px directory gaps.
- Shape: 3px controls; square image and content panels; no pill system or ornamental shadows.
- Images: genuine 2025 exhibition photos labelled by edition, clean official portrait crops, logos contained without distortion, fixed reserved dimensions.
- Motion: 220ms interaction transitions; 700ms transform-only heading entry; count-up supports reduced motion and visible SSR content. No hide-before-init reveals.
- Layers: header 20, dropdown 30, modal top-layer 50, skip-link 100.
- Colour modes: system preference with semantic variable tokens. Photographic overlays maintain their contrast in either mode.

Contextual Taste exceptions follow the user brief: full photographic hero; three co-located brand identities; explicit event dates/status; full directories on dedicated pages; official brand artwork and partnership roles preserved. User content accuracy and accessibility take precedence over decorative skill patterns.
