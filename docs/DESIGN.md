# Design system

Design read: international B2B energy event, confident editorial and photographic, accessible to a broad professional audience.
Taste dials: DESIGN_VARIANCE 5, MOTION_INTENSITY 4, VISUAL_DENSITY 4.

- Brand: User-supplied BHARAT ELECTRICITY logo; green #08752c for headings and links, orange #f56a16 for rules and accents, accessible orange #b94a06 for display type, white #ffffff for every surface.
- Typeface: self-hosted variable Manrope, 16px body, 1.7 line height; measured display hierarchy with tight heading tracking.
- Width: 1280px content, 48px desktop gutters, 20px mobile gutters.
- Spacing: 88px desktop and 58px mobile section rhythm; 24-30px directory gaps.
- Shape: 3px controls; square image and content panels; no pill system or ornamental shadows.
- Images: genuine 2025 exhibition photos labelled by edition, clean official portrait crops, logos contained without distortion, fixed reserved dimensions.
- Motion: 220ms interactions, 700ms heading entry, 680ms scroll reveals, decorative parallax, line drawing and the supplied first-visit Lottie. Important content is readable before scripts initialise. All decorative motion respects reduced motion.
- Layers: header 20, dropdown 30, modal top-layer 50, skip-link 100.
- Colour mode: light only. White backgrounds are retained even when the operating system prefers dark mode. Photographs are displayed without dark overlays.

Contextual Taste exceptions follow the user brief: white split hero with genuine photography; a single BHARAT ELECTRICITY identity; explicit event dates/status; full directories on dedicated pages; official brand artwork and partnership roles preserved. User content accuracy and accessibility take precedence over decorative skill patterns.
